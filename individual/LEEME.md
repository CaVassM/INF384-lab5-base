# Entregable individual

Cada integrante crea en esta carpeta un archivo con su código PUCP como nombre: `individual/<codigo>.md`.

El archivo lo crea y lo sube el propio integrante, con su usuario de GitHub.

```
# <codigo> · <nombre>

## C1 · Mi pull request
- Link:
- Qué control implementa o qué corrige:
- Qué detiene o qué deja pasar después de mi cambio:

## C2 · Lo que cambiaría
- Decisión del equipo que cambiaría:
- Por qué:
- Riesgo que acepta la decisión que tomó el equipo:
```
