# Monedero Andino

API de la billetera digital Monedero Andino. Repositorio base del Laboratorio 5 de INF384.

## Contenido

| Ruta | Qué es |
|---|---|
| `src/` | Código de la API. |
| `test/` | Pruebas unitarias. |
| `infra/` | Infraestructura en Terraform. |
| `.github/workflows/ci.yml` | Pipeline. |
| `DECISIONES.md` | Entregable del equipo. |
| `individual/` | Entregable de cada integrante. |

## Uso en el laboratorio

1. Un integrante del equipo hace fork de este repositorio a su cuenta personal. El fork debe ser público.
2. Ese integrante agrega a los demás como colaboradores en **Settings > Collaborators**. Cada uno acepta la invitación desde su correo o desde GitHub.
3. Habilitar Actions en el fork, en la pestaña **Actions**.
4. Todo el equipo trabaja sobre ese fork, con ramas y pull requests contra `main` del fork.

No se necesita cuenta de AWS ni secrets. Nada se despliega.
